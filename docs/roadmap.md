# QR Werk roadmap

Ideas in this document are planned concepts, not features of the current release.

## Planned QR content types

- Microsoft Teams chat: create a QR code that opens a chat with a selected person or a prepared Teams chat link. The exact fields and supported Teams URL format must be validated before implementation.
- Geolocation assistance: fill latitude and longitude from the device's current location or let the user choose a place through Apple Maps/MapKit. Current-location access must remain optional, require explicit iOS permission and clearly explain any Apple Maps data transfer before implementation.

## Planned scan workflows

- Control mode: compare scanned codes with an expected list and clearly show missing, unexpected and duplicate items.
- Inventory mode: assign scans to rooms, locations or newly created groups directly while scanning.

## Planned usability and export improvements

- Compact help mode: let experienced users hide optional explanatory text while keeping essential labels, warnings and accessible information available.
