# Scanning

## Camera and batch scanning

A normal camera scan opens the result after one successful recognition. **Batch Scan** stores several codes without returning to the overview after every result.

The scanner controls provide manual entry, flashlight, 1×/2× zoom and scanner options. Scanner options include:

- **Standard:** square target for QR codes and everyday scanning
- **Wide:** wide target for linear barcodes
- **Full image:** larger target for a tripod or difficult positioning
- **Scan filter:** accept codes by prefix, suffix and exact total character count
- **Scan sound:** quickly enable or disable acoustic confirmation

When exactly one unambiguous code is visible, QR Werk can recognize it outside the displayed target. If several codes are visible, the selected area helps determine which code should be used.

## Batch settings

Under **Settings → QR Codes & Scanning**, configure duplicates, delay and autofocus. A one-second delay and autofocus enabled are recommended. Duplicate handling can allow repeats, block them within the current run or compare against existing history.

## Scan filter

A prefix means “the code must begin with this value”; it is not added to the result. A suffix means “the code must end with this value”. Exact character count is the complete length, including letters, digits, spaces and symbols. Every filled condition must match.

Use the built-in test field before scanning important batches. Disable the filter afterwards if later jobs use different code formats.

## Image import

Select one or more photos. If multiple codes are detected, review the list and save all or only the selected items. Cancel discards unsaved results. Recognition takes place locally on the device.
