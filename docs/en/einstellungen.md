# Settings

## About and user guide

**About QR Werk** contains the app version, supported barcode types, release notes, privacy information, license, source code and upstream attribution. The offline **User Guide** uses the same chapters as this repository.

## QR Codes & Scanning

This page groups QR-code display, duplicate handling, scan delay, autofocus, scan filters and result actions. The scan filter accepts codes by prefix, suffix and/or exact total character count; it does not search for one specific asset.

The scanner options also provide direct access to the standard, wide and full-image scan areas, the filter and the scan-sound toggle.

## Data management

This area contains automatic history, code import, optional iCloud synchronization, backup, restore and export. The history has no artificial entry limit.

iCloud is off by default. When enabled, it synchronizes history, groups, bookmarks, duplicate detections, trash and the user-selected device label through the user's private CloudKit database. App settings and Apple's personal device name are not synchronized.

## Appearance and controls

Choose system, light, dark or black appearance, a preset or custom accent color and the preferred start view. The header always displays **QR Werk**. Orientation can follow iOS or be locked where supported.

Under **Scan feedback**, choose vibration, one of four scan sounds and its relative volume. The final loudness still depends on the device's iOS volume.

## Reset

A reset can remove data, settings or both. Create a backup first if the records are important. Items in the synchronized trash are part of the app data.
