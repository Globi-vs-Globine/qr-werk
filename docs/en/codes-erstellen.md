# Create codes

Open **Create**, select a content type and complete the displayed fields. QR Werk supports free text, URLs, contacts, phone numbers, SMS, email, Wi-Fi access and geographic locations.

Check all information before sharing or printing. Use strong contrast, keep the white quiet zone around the code, do not distort it and test printed codes before producing many copies. QR code colors, error correction and the optional outer frame are configured under **QR and scan settings → QR code style**.
