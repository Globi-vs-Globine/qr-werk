# History and groups

History contains scanned, imported and created codes. Open an entry to see its content, type, timestamps and device information.

Use **Actions → Manage groups** to create, rename or delete groups. Use **Manage entries** to select several records and move them together. Groups can be collapsed; **Without group** contains new unsorted records.

Bookmarks are an additional marker and do not replace groups. Before deleting important data, create a backup or export. With iCloud Sync enabled, individual deletions are synchronized to connected devices.
