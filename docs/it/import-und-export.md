# Importazione, esportazione e backup

Nella cronologia tocca direttamente **Esporta**, quindi scegli elementi visibili, gruppi o singoli codici. Esporta i dettagli in una cartella di lavoro Excel formattata (`.xlsx`), in CSV/TXT, solo i codici oppure copia i valori. Il file Excel include una riga di intestazione bloccata, filtri e vere celle data.

Per importare un elenco, apri **Impostazioni → Gestione dati → Importa codici** e incolla un valore per riga. Le righe vuote vengono ignorate e puoi scegliere il gruppo di destinazione.

L’importazione immagini si trova nella panoramica di scansione. Seleziona una o più immagini, controlla i codici rilevati e salva tutti o solo quelli scelti.

Excel/CSV/TXT e iCloud non sostituiscono un backup indipendente. Usa anche **Backup** per i dati importanti.
