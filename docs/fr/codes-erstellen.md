# Créer des codes

Ouvrez **Créer**, choisissez le type de contenu et remplissez les champs. QR Werk prend en charge texte, URL, contacts, numéros de téléphone, SMS, e-mail, accès Wi-Fi et positions géographiques.

Avant l’impression, vérifiez les données, utilisez un contraste élevé, conservez la zone blanche autour du code et ne déformez pas l’image. Le style, la correction d’erreur et le cadre extérieur se règlent dans les réglages QR.
