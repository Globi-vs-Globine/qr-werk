# Historique et groupes

L’historique contient les codes scannés, importés et créés. **Actions → Gérer les groupes** permet de créer, renommer ou supprimer des groupes. **Gérer les entrées** permet de sélectionner plusieurs éléments et de les déplacer ensemble.

Les favoris complètent les groupes sans les remplacer. Créez une sauvegarde avant une suppression importante. Avec la synchronisation iCloud active, les suppressions sont transmises aux appareils connectés.
