# Historique et groupes

L’historique contient les codes scannés, importés, saisis manuellement et créés. Ouvrez un élément pour voir son contenu, son type, ses dates, les doublons et le libellé de l’appareil.

Utilisez **Groupes** dans la barre inférieure pour créer, renommer ou supprimer des groupes. Pour déplacer un élément, touchez ses trois points, choisissez **Déplacer vers un groupe**, puis la destination. Les favoris complètent les groupes.

Supprimer place d’abord l’élément dans la **Corbeille**. Il peut y être restauré ou supprimé définitivement. **Vider la corbeille** demande une confirmation. Avec iCloud actif, corbeille et restaurations sont synchronisées entre les appareils.

Le bouton direct **Exporter** permet de choisir les éléments visibles, certains groupes ou des codes individuels.
