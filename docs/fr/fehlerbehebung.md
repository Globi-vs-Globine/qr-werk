# Questions fréquentes

Si la caméra reste noire, vérifiez l’autorisation sous **Réglages iOS → Confidentialité et sécurité → Appareil photo**, puis redémarrez QR Werk. Pour une image non reconnue, utilisez un original plus net, complet et contrasté.

Si une ancienne icône reste visible, supprimez l’app de l’appareil de test et réinstallez-la avec Xcode. Dans Xcode, le jaune indique un avertissement et le rouge une erreur.
