# Codes erstellen

## Neuen Code erzeugen

Öffne in der unteren Navigation **Erstellen**. Wähle den gewünschten Inhaltstyp und fülle die angezeigten Felder aus.

Je nach Typ kann QRWerk beispielsweise Texte, Internetadressen, Kontaktdaten, Telefonnummern, E-Mail-Angaben oder WLAN-Informationen in einem QR-Code abbilden.

## Inhalt kontrollieren

Prüfe alle Angaben vor dem Teilen oder Drucken. Ein erzeugter QR-Code enthält genau die eingegebenen Informationen. QRWerk kann eine falsche Internetadresse oder ein fehlerhaftes Passwort nicht automatisch erkennen.

## Speichern und teilen

Nach dem Erstellen kannst du den Code anzeigen und – abhängig von der Plattformfunktion – speichern, kopieren oder teilen.

Für gedruckte Codes gelten folgende Empfehlungen:

- Verwende einen deutlichen Hell-Dunkel-Kontrast.
- Lasse einen freien Rand um den Code.
- Verzerre das Seitenverhältnis nicht.
- Teste den Ausdruck vor einer größeren Produktion.
- Verwende bei langen Inhalten ausreichend große Abmessungen.

## Barcode oder QR-Code?

QR-Codes eignen sich für Texte und strukturierte Informationen. Eindimensionale Barcodes sind häufig auf bestimmte Zeichensätze und Längen beschränkt. Wähle ein Format, das zum Zielsystem passt.
