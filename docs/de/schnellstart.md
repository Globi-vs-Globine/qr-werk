# Schnellstart

## 1. QRWerk öffnen

Beim normalen App-Start öffnet QRWerk direkt den Kamerascanner. Richte die Kamera auf einen QR-Code oder Barcode. Der Code muss vollständig und möglichst scharf im Kamerabild zu sehen sein.

Beim ersten Start fragt iOS nach dem Kamerazugriff. Wähle **Erlauben**, damit QRWerk Codes aufnehmen kann.

## 2. Einen Code scannen

1. Halte das Gerät ruhig über den Code.
2. Sorge für ausreichendes Licht und vermeide Spiegelungen.
3. Nach der Erkennung öffnet QRWerk die Ergebnisansicht.
4. Je nach Inhalt kannst du den Wert kopieren, teilen, öffnen oder anderweitig verwenden.

Der erkannte Wert wird im Protokoll gespeichert, sofern die Protokollierung in den Einstellungen aktiviert ist.

## 3. Zur Scan-Übersicht wechseln

Schließe den nativen Scanner mit **Schließen**. Wenn du später in der unteren Navigation auf **Scannen** tippst, erscheint die Übersicht mit drei Möglichkeiten:

- **Scannen mit der Kamera** für einen einzelnen Code
- **Batch scannen** für mehrere Codes nacheinander
- **Bild importieren** für Codes aus Fotos oder Bildern

## 4. Einen Code aus einem Bild lesen

Wähle **Bild importieren**, erlaube den Zugriff auf deine Fotos und markiere ein oder mehrere Bilder. QRWerk zeigt die erkannten Codes vor dem Speichern an. Du kannst alle oder nur ausgewählte Ergebnisse übernehmen.

## Gut zu wissen

- QRWerk arbeitet grundsätzlich offline.
- Kamera- und Fotozugriff werden nur für die von dir ausgelösten Funktionen verwendet.
- Batch-Scans erscheinen zunächst unter **Ohne Gruppe** und können später gemeinsam verschoben werden.
